# dx-sprint

臺師大微積分乙（一）期末衝刺用的互動學習網頁。範圍是課本 4.5 到 8.7。

線上網址：https://iammay22.github.io/dx-sprint/

## 裡面有什麼

- 考古題 101 題：109 到 114 學年共 8 份期末考，每題附提示、逐步解和答案
- 指定習題 97 題：照第 9 到 14 週的進度排，首頁會標出這週
- 13 個觀念單元：重點、要背的公式、常見錯誤
- 速練：公式翻卡、招式判斷
- 模擬考：照考古題比重隨機出卷，或寫整份考古題，限時 110 分鐘
- 跨裝置同步：每台裝置輸入同一組同步代碼，進度就會合併

## 同步後端設定

1. 開一份新的 Google 試算表
2. 擴充功能 > Apps Script，把 `apps-script/Code.gs` 整份貼上
3. 部署 > 新增部署作業 > 類型選「網頁應用程式」，執行身分選自己，存取權限選「所有人」
4. 複製部署網址，填進 `index.html` 裡的 `const ENDPOINT=''`

之後改了 Code.gs 要重新部署成新版本，網址才會更新。
